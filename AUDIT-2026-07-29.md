# voicebridge bug audit, 2026-07-29

Four read-only reviewers (relay+page, session/state, STT/inject/cross-platform, CLI/install). Top items verified against live code. Grouped by fix priority, not by reviewer.

Severity: CRASH / SECURITY / DATA-LOSS / SILENT-FAIL / MINOR. Status: CONFIRMED (checked live) / PLAUSIBLE (needs a live precondition) / REPORTED.

---

## Tier 1, confirmed, hits current Mac users, fix first

1. **call.py:6478 | SILENT-FAIL (big) | CONFIRMED.** `/events` SSE loop rebinds the subscriber queue `q` to `core.pending_question()` (a dict), so next iteration `q.get(timeout=0.4)` raises TypeError and the stream dies after ~0.4s; `_SUBS.discard(q)` then discards the dict, leaking the real queue. Every phone reconnect (2 to 3x/sec) leaks a dead queue into `_SUBS`. Net: real-time push is effectively dead, phone silently falls back to slow polling. Fix: rename the question var (`qn`/`qid`), leave the queue `q` alone.

2. **call.py:~393 (_read_tts) | SILENT-FAIL | CONFIRMED.** Calls bare `["ffmpeg", ...]` instead of the resolved `FFMPEG` constant used elsewhere. Under launchd's minimal PATH, ffmpeg isn't found, opus encoding silently fails, full WAVs cross the tunnel, silently undoing the reply-latency win. Fix: use `FFMPEG`.

3. **call.py:265,320,6614 | DATA-LOSS/CRASH | CONFIRMED.** `_ASKED` idempotency ledger is an unlocked module dict. Check-then-reserve (6614/6625) isn't atomic, two racing `/ask` with the same id can both inject (prompt typed twice); `_prune_asked` (320) iterates-then-pops and can raise `RuntimeError: dict changed size` under concurrency, dropping the connection. Fix: guard `_ASKED` reads/writes/prune with a lock; snapshot before pruning.

4. **.claude-plugin/marketplace.json:14 vs plugin.json:4 | DISTRIBUTION | CONFIRMED.** marketplace.json = 2.20.4, plugin.json = 2.20.8. The plugin platform installs the marketplace.json version, so plugin users are pinned 4 releases behind and get none of 2.20.5 to 2.20.8. Fix: bump marketplace.json in lockstep; keep both in sync going forward (release step).

## Tier 2, isolation & lifecycle (security-relevant)

5. **talkd.py (tty_for_sid / phone_enabled / session_closed) | SECURITY | PLAUSIBLE (needs pid reuse).** Stale `OWNERS`/`PHONE` entries + pid-only liveness. If a phone-enabled session crashes and its pid is later reused by a different session that never opted in, `tty_for_sid` can resolve to the new session's terminal, phone prompt lands in a session the user never shared. Root of the cluster below. Fix: bind sid to pid (store + compare, with start-time/boot-generation); reap `OWNERS/sid` and `PHONE/sid` in `session_closed`; periodically reap PHONE entries whose sid is dead.

6. **bin/vb off branch | SECURITY | CONFIRMED.** `vb off` ("stop everything, everywhere") does not call `call.off()` / reap the tunnel, nor clear `PHONE`/`CALL_OWNER`. The public relay + tunnel keep running after the user believes everything is shut down. Fix: `off` also tears down the call relay and clears PHONE/CALL_OWNER.

7. **talkd.py _is_claude_pid / session_alive | SILENT-FAIL | PLAUSIBLE.** Watchdog liveness is "pid alive and named claude", not rebound to the sid, so a reused pid owned by a *different* Claude session reads as the original still alive, mic stays open, dead session's transcript read aloud. Same root fix as #5.

8. **talkd.py daemon_alive (PID file) | SILENT-FAIL | REPORTED.** Trusts a reused talkd PID; `ensure_daemon` can then skip starting the daemon while reporting success (mic never opens). Fix: gate on `_daemon_pids()` (pgrep), not the PID file alone.

9. **core.py kokoro port (and stt whisper port) | SILENT-FAIL | REPORTED.** Kokoro/whisper bind a fixed loopback port, not a per-uid port (the relay already went per-uid). On a multi-user Mac, user B routes synthesis through user A's server. Fix: per-uid port, health check ownership. (Same class as the relay port bug we already fixed.)

## Tier 3, cross-platform (blocks Linux/Windows; not current Mac users). Defer until we target other platforms.

10. **core.py:~1346-1428 | HIGH off-Mac.** TTS hardcoded to afplay/say; the final `say` is unguarded and crashes the worker; `oslayer` TTS functions are dead code. Voice replies are entirely dead on Linux/Windows.
11. **inject.py:94-116 | HIGH off-Mac.** `press_enter(expect_app=...)` runs the osascript guard before the IS_MAC check, so it always returns False off-Mac, phone approve/yes never delivers; empty-expect path sends a blind Enter with no wrong-window guard.
12. **inject.py:198-200 | HIGH off-Mac.** `paste_text` non-Mac ignores expect_app/target_tty (no wrong-window guard) and returns True even when the OS-layer paste did nothing, prompt typed into the wrong window, or silently lost and marked delivered.
13. **oslayer.py:114-116 | HIGH off-Windows.** `stop_all_speech` runs `taskkill /F /IM powershell.exe`, force-kills every PowerShell process on the machine. Fix: track and kill only the TTS pid.
14. **inject.py:73-91 | MED off-Mac.** `press_shift_tab` hard-returns False off-Mac, mode cycling silently no-ops.
15. **oslayer.py:117-118 | MED off-Linux.** stop only kills aplay, not espeak-ng/espeak.

## Tier 4, install / distribution robustness (the class we already hit)

16. **bin/vb:949 | CRASH | CONFIRMED-ish.** `vb call tunnel` references `_sh` (shutil) imported only in the `phone` branch, UnboundLocalError on the documented `call tunnel` path. Fix: import shutil at module top.
17. **install.sh:69-76 | SILENT-FAIL.** Clone installs never register the SessionStart hook, so auto-update + first-run hint never fire for clone users. Fix: add SessionStart to WANTED.
18. **bin/vb:1219-1222 (vb update) | SILENT-FAIL.** `vb update` rewrites slash commands without install.sh's `/opt/homebrew/bin/vb -> resolved path` sed; on Intel Macs the commands point at a nonexistent path and silently fail. Fix: apply the same substitution.
19. **bin/vb doctor:1263-1306 | SILENT-FAIL.** doctor false-FAILs plugin installs (checks only ~/.claude, not the plugin dir) and never checks the `vb` PATH symlink, the exact class of the live bug we hit. Fix: detect plugin installs; add a `which vb` resolves-to-this-repo + executable check.
20. **hooks/on_session.py:64 (+ statusline/teach) | MED.** Install type inferred from `.git` presence; a plugin cache that is a git clone would get background `git pull` into the platform-managed dir and wrong update instructions. Fix: detect plugin context explicitly, not by `.git`. (Verify a real plugin install has `.git` first.)
21. **install.ps1 __install_hooks__ | LOW (Windows).** Registers 3 hooks, missing SessionEnd/SessionStart, reintroduces "voice outlives closed session".
22. **install.sh:116 | LOW.** `pip3 install --user qrcode || true` can fail silently under PEP 668 and installs to the wrong interpreter, `vb phone` then has no QR.

## Tier 5, correctness edges / performance

23. **core.py last_assistant_text / assistant_replies_after | PERF.** Docstring says tail-read but they `read_text().splitlines()` the whole (multi-MB) transcript, on the hot capture/daemon path, hundreds of ms latency on long sessions. Fix: bounded tail seek like latest_activity does.
24. **talkd.py:1447/1483 | DATA-QUALITY | PLAUSIBLE.** `prev` keyed by transcript path; if the path changes for a sid (compaction/resume), the whole backlog is re-spoken. Fix: key baseline by sid.
25. **talkd.py ACTIVE/LAST/VOICED writes | SILENT-FAIL.** Non-atomic write_text racing daemon reads yields truncated JSON, daemon sees "no active session" for that tick. Fix: temp + os.replace (as set_hud does).
26. **core.py active_session_state tail window | SILENT-FAIL.** A final record larger than the 64KB tail window means no full line parses, state falls to "idle" while actually "working", phone orb reads finished when it isn't. Fix: grow window / read back until one full record.
27. **stt.py whisper_up | SILENT-FAIL.** Treats any HTTP reply on the port as "whisper ready", port collision routes transcription to the wrong server. Fix: probe a whisper-specific signature.
28. **core.py _vtuple / check_for_update | MINOR.** `_vtuple` breaks on pre-release/unequal-length versions; `check_for_update` stamps the timestamp before the network call (a brief outage suppresses checks for 6h). 
29. **talkd.py _foreign_script | MINOR.** Diacritics (café, résumé) count as foreign and can drop a real prompt. Fix: NFKD strip / only trigger on genuinely non-Latin scripts.
30. **talkd.py owner_pid / owner_sid | FRAGILITY.** Assumes the Claude process comm is exactly `claude`; a `node`/wrapper launch breaks owner resolution. owner_pid also runs on every prompt (up to 12 sequential `ps`, 5s hook budget). Fix: match args/exe too; cache the owner pid per session.

## Self-heal opportunities (feed the Layer-1 auto-doctor)
- Broken/foreign `vb` symlink, re-link to ~/.local/bin (the live bug we hit). Highest value.
- Slash commands with a dead hardcoded vb path, re-substitute.
- Orphaned relay/tunnel with no owning session, reap.
- Stale PID files (watch/talkd/tunnel/orb/tts), verify name/args before trusting (pid-reuse safe).
- Missing SessionStart hook on clone installs, detect + offer to register.
- Plugin cache being auto-git-pulled, detect plugin context, skip.
- Kokoro engine selected but server down, already auto-healed by ensure_kokoro_server; surface in doctor.
